## 🛠️ Projects

### Dolioo Platform

A comprehensive social platform ecosystem consisting of multiple applications and services.

#### Dolioo Users App

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/imuhammadnadeem/dolioo_users)

A Flutter-based mobile application for end users to discover businesses, interact with content, manage profiles, and engage with the Dolioo platform.

**Key Features:**

- Clean architecture with GetX and Redux state management
- Firebase integration for backend services
- Real-time messaging with Socket.IO
- Advanced caching with cached_network_image
- Image/video picker, editor, and processing
- Push notifications with Firebase Cloud Messaging
- Geolocation and mapping services
- QR code generation and scanning
- Calendar integration
- WebView support for embedded content

**Technologies:** Flutter, Dart, GetX, Redux, Firebase, Socket.IO, Dio

#### Dolioo Partners App

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/imuhammadnadeem/dolioo_partners)

A Flutter application designed for business partners to manage their presence on the Dolioo platform.

**Key Features:**

- Partner dashboard and analytics
- Business profile management
- Content management system
- GetX and Redux state management
- Real-time updates via WebSocket
- Firebase integration

**Technologies:** Flutter, Dart, GetX, Redux, Firebase, Socket.IO

#### Dolioo Backend API

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/imuhammadnadeem/Dolioo-Backend)

A robust Node.js REST API backend supporting the entire Dolioo platform.

**Key Features:**

- Express.js RESTful API
- MongoDB database with Mongoose ODM
- Socket.IO for real-time communication
- Firebase Admin SDK integration
- JWT authentication
- AWS S3 file storage
- Email services with Nodemailer
- Twilio SMS integration
- Rate limiting and security with Helmet
- Swagger API documentation
- Scheduled tasks with node-cron

**Technologies:** Node.js, Express.js, MongoDB, Socket.IO, Firebase Admin, AWS S3, JWT
